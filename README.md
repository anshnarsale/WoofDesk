## ✨ Why You'll Love Buddy

- 🐾 **True Desktop Overlay**: Transparent, frameless, and floating above all your apps. No ugly square borders.
- 🎯 **Never Steals Focus**: Built with `focusable: false` so clicking, petting, or dragging Buddy never interrupts your typing in VS Code, Word, or games.
- 🎨 **60 FPS Procedural Animations**: High-DPI Canvas vector engine with 17 expressive states — trotting, jumping with gravity physics, tail wagging, sniffing, sleeping with `Z z z` bubbles, and celebratory confetti!
- ⏱️ **Study Pomodoro Timer**: Buddy sits peacefully by your side while you focus, then celebrates when your session finishes.
- ⏰ **Gentle Reminders**: Set reminders (`+15m`, `+30m`, `+1h`) — Buddy alerts you with cute speech bubbles, soft chimes, and Windows notifications.
- ✅ **Daily Tasks & Notes**: Check off to-dos to earn Buddy virtual treats (`🦴`) and happiness points, or jot quick thoughts on the scratchpad.
- 🍖 **Tamagotchi Care**: Feed treats, toss a ball (`🎾`), or let him nap to recharge his energy.
- 👻 **Click-Through & Quiet Mode**: Instant toggles from the Windows System Tray to silence Buddy during meetings or let clicks pass straight through him.

## 🚀 Quick Launch

### Option 1: One-Click Run (Easiest)
Double-click **`launch.bat`** to start Buddy immediately.

### Option 2: Run from Source
```powershell
npm install
npm start
```

### Option 3: Standalone Executables
- **Instant Unpacked**: `release\win-unpacked\Desktop Pet Dog.exe`
- **Single Portable File**: `release\Desktop Pet Dog 1.0.0.exe`
